BPBD DIY menyebut APAR sebagai alat pemadam api portabel yang dirancang untuk digunakan satu orang, dan efektif untuk penanganan dini saat terjadi kebakaran. Kata kuncinya dini. Damkar Kota Cirebon memberi batasnya: jangan memadamkan api jika asap sudah tebal atau api membesar. Pada keadaan itu, segera evakuasi dan panggil bantuan.

## Empat langkah baku

BPBD DIY menuliskan urutan penggunaan APAR dalam empat tahap yang disingkat PASS.

1. **Tarik.** Tarik pin pengaman yang terdapat pada alat pemadam api dengan kuat, sampai tuas pemicu bebas digunakan.
2. **Arahkan.** Arahkan nosel atau moncong alat pemadam api langsung ke dasar api, bukan ke bagian atas nyala api. Api harus dimatikan dari sumbernya untuk mencegah penyebaran lebih lanjut.
3. **Tekan.** Tekan tuas pemicu dengan kuat dan terus-menerus. Jangan lepas tekanan sampai api sepenuhnya padam atau bahan pemadam habis.
4. **Sapukan.** Lakukan gerakan menyapu dari sisi ke sisi, supaya seluruh area yang terkena api terpapar bahan pemadam secara merata. Tetap fokus ke dasar api.

> Jaga jarak aman saat menyemprot. BPBD DIY menekankan hal ini tanpa menyebut angka pasti.

## Empat aturan memasangnya

Menurut BPBD DIY, APAR harus berada di lokasi strategis yang mudah diakses dan terlihat oleh semua orang, supaya dapat dipakai dengan cepat dalam keadaan darurat.

- **Posisi strategis.** Dipasang di tempat yang mudah terlihat dan dijangkau semua orang.
- **Pemasangan aman.** Dipasang dalam posisi menggantung dan terlindungi.
- **Ketinggian.** Paling tinggi 1,2 meter dari lantai, supaya mudah diambil.
- **Suhu ruangan.** Tidak boleh dipasang di ruangan bersuhu lebih dari 49 derajat Celsius atau kurang dari 4 derajat Celsius.

## Hubungannya dengan peta

Kalau rumah Anda berada di gang berkelas selang saja, mobil pemadam berhenti jauh dan air butuh waktu lebih lama untuk sampai. Panel Titik henti di lembar kerja menunjukkan berapa lama. Menit-menit sebelum air datang itulah waktu penanganan dini yang dimaksud BPBD DIY.
