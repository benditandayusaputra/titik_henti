## Hanya untuk api yang masih kecil

Jangan memadamkan api jika asap sudah tebal atau api membesar. Segera evakuasi dan panggil bantuan.

## Empat langkah

1. **Tarik** pin pengaman sampai tuas pemicu bebas.
2. **Arahkan** nosel ke dasar api, bukan ke nyala api.
3. **Tekan** tuas terus-menerus sampai api padam atau isinya habis.
4. **Sapukan** dari sisi ke sisi. Jaga jarak aman.

## Memasang APAR

- Di tempat yang mudah terlihat dan dijangkau semua orang.
- Menggantung dan terlindungi, paling tinggi 1,2 meter dari lantai.
- Tidak di ruangan bersuhu lebih dari 49 derajat Celsius atau kurang dari 4 derajat Celsius.
