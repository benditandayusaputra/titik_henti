## Beri peringatan

Teriakkan "KEBAKARAN!", tekan alarm kebakaran jika tersedia, dan peringatkan orang di sekitar lokasi.

## Padamkan hanya bila api masih kecil

- Pakai APAR atau karung goni yang dibasahi air.
- Api dari korsleting: matikan listrik rumah.
- Api dari minyak goreng: jangan pernah disiram air. Selimuti pelan-pelan dengan karung goni basah, jangan dilempar.

> **Jangan memadamkan api jika asap sudah tebal atau api membesar.** Segera evakuasi dan panggil bantuan.

## Keluar

- Tutup pintu ruangan yang terbakar, jangan dikunci.
- Jangan mengumpulkan barang. Berjalan, jangan lari.
- Asap tebal: merangkak, tutup hidung dan mulut dengan kain basah.
- Sebelum membuka pintu, tempelkan punggung tangan ke daun pintu, lalu periksa gagangnya. Bila panas, pakai jalur lain.
- Bantu anak-anak, lansia, dan penyandang disabilitas.
- Pakaian terbakar: berhenti, berbaring, tutup muka, berguling perlahan.
- Bila tidak dapat keluar: tutup pintu, sumbat celahnya dengan kain basah, berada dekat jendela, dan beri tanda dengan kain, lampu, atau suara.

## Melapor

Hubungi **Jakarta Siaga 112**, bebas pulsa, atau datang ke pos sektor Dinas Gulkarmat terdekat. Sebutkan lokasi lengkap dengan nama gang, situasi kebakaran, dan apakah ada orang yang terjebak.
