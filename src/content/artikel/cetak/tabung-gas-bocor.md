## Urutan tindakan

1. **Jangan panik.**
2. **Segera lepas regulator dari tabung.**
3. **Tutup sumber api dengan kain basah.** Pegang dengan kedua tangan seperti menjepit dan angkat menutupi kepala. Arah menutup sejajar dengan angin. Dekati menyamping, kaki kuda-kuda, badan sedikit merunduk. Tutup menyeluruh, lalu pastikan api benar-benar mati, cirinya keluar asap putih.
4. **Buka pintu dan jendela** agar gas keluar.

## Dua larangan

> **Jangan menyalakan saklar lampu** bila tercium bau gas yang menyengat.

> **Jangan menyiram air** langsung ke sumber api atau kompor.

## Bila api sudah besar

Jangan dipadamkan sendiri bila asap sudah tebal atau api membesar. Keluar, tutup pintu ruangan yang terbakar, dan hubungi **Jakarta Siaga 112**.
