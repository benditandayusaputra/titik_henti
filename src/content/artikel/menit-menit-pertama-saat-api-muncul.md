Dinas Pemadam Kebakaran Kota Cirebon menulisnya dalam satu kalimat: detik-detik pertama sangat menentukan keberhasilan evakuasi. Yang diputuskan pada menit-menit itu bukan cara memadamkan api, melainkan apakah api masih boleh dilawan atau sudah waktunya keluar.

## Beri peringatan lebih dulu

Menurut Damkar Kota Cirebon, begitu Anda melihat api atau mencium bau asap yang mencurigakan:

1. Teriakkan "KEBAKARAN!"
2. Tekan alarm kebakaran jika tersedia.
3. Peringatkan orang yang berada di sekitar lokasi.

Di gang padat, rumah tetangga sering hanya berbatas satu dinding, jadi peringatan ini untuk mereka juga, bukan hanya untuk orang serumah.

## Putuskan: padamkan atau keluar

Padamkan hanya bila api masih kecil. Damkar Kota Banda Aceh menyebut alat yang bisa dipakai: APAR atau karung goni yang dibasahi air. Damkar Kota Cirebon menambahkan syaratnya: Anda tahu cara memakai APAR.

> **Jangan memadamkan api jika asap sudah tebal atau api membesar.** Segera evakuasi dan panggil bantuan. Ini kalimat Damkar Kota Cirebon.

Dua keadaan khusus:

- **Api dari korsleting.** Damkar Kota Banda Aceh meminta segera mematikan listrik di rumah.
- **Api dari minyak goreng.** BPBD NTB menegaskan jangan pernah menyiram api dengan air, karena air lebih berat dari minyak dan justru membantu api menyebar. Pakai karung goni basah.

BPBD NTB juga menuliskan cara memakai karung goni basah:

1. Jangan melempar karung goni ke sumber api, karena melempar memberi suplai oksigen dan api bisa mendadak membesar.
2. Jangan memegang karung goni dengan tangan terbuka. Tutup telapak tangan dengan ujung atas kiri dan kanan karung.
3. Dekati sumber api perlahan. Jadikan karung goni penghalang antara Anda dan api, lalu selimuti sumber api pelan-pelan sampai tertutup semua.
4. Setelah tertutup sempurna, lepaskan pegangan dan segera menjauh. Amati apakah api masih menyala, dan panggil bantuan pemadam kebakaran.

## Kalau memutuskan keluar

- **Tutup pintu ruangan yang terbakar, tetapi jangan dikunci.** Damkar Kota Banda Aceh memintanya supaya api tidak menjalar ke ruang lain dan pintu mudah dibuka saat api akan dipadamkan. Damkar Kota Cirebon menjelaskan manfaatnya: menghambat penyebaran api, mengurangi masuknya oksigen, dan mengulur waktu bagi evakuasi serta kedatangan petugas.
- **Jangan mengumpulkan barang.** Barang berharga dapat diganti, nyawa tidak.
- **Berjalan dengan tenang, jangan lari.** Ini pesan Damkar Kota Banda Aceh.
- **Bila ada asap tebal, merangkak.** Udara bersih berada dekat lantai. Tutup hidung dan mulut dengan kain basah bila memungkinkan.
- **Periksa pintu yang tertutup sebelum dibuka.** Tempelkan punggung telapak tangan ke daun pintu, lalu periksa gagangnya. Bila panas, pindah melalui jalur lain.
- **Bantu anak-anak, lansia, dan penyandang disabilitas.**
- **Bila pakaian terbakar,** BPBD NTB meminta berhenti, berbaring, menutup muka, lalu berguling perlahan. Jangan berlari, karena berlari membesarkan api dengan oksigen.

## Kalau tidak dapat keluar

Damkar Kota Cirebon menuliskan urutannya:

1. Tutup pintu.
2. Sumbat celah pintu dengan kain basah.
3. Berada dekat jendela untuk mendapat udara.
4. Beri tanda kepada petugas dengan kain, lampu, atau suara.

## Melapor

Di Jakarta, Pemprov DKI meminta warga yang memerlukan bantuan pemadam menghubungi **Jakarta Siaga 112**, bebas pulsa, atau datang langsung ke pos sektor Dinas Gulkarmat terdekat.

Damkar Kota Cirebon menyebut tiga hal yang perlu disampaikan saat melapor:

- Lokasi lengkap
- Situasi kebakaran
- Apakah ada orang yang terjebak

Di permukiman padat, sebutkan nama gang dan patokan terdekat. Nama jalan besar saja tidak menunjukkan gang mana yang terbakar.

## Hubungannya dengan peta

Di gang berkelas selang saja, mobil pemadam berhenti jauh sebelum rumah dan selang harus digelar dengan tangan. Panel Titik henti di lembar kerja menunjukkan berapa meter selang dan berapa gulung yang dibutuhkan untuk rumah yang Anda pilih. Angka itu adalah jeda antara laporan Anda dan air yang benar-benar sampai.
